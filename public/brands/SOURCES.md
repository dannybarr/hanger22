# Brand marks

Official marks on the Brand Story wall. Each file is the mark as published at the source below. Marks are not redrawn.

Piece houses come first (Stone Island, Moncler, Palm Angels, Supreme, and the other houses already in the catalogue), then the grail houses named for the wall. Kapital and Chrome Hearts are absent: no official mark could be confirmed. The English Wikipedia Bape file is a non-free 260px image and was not used.

The Kith file on Wikimedia paints a full-bleed black plate over the letters. `kith.svg` keeps the wordmark paths from that file and omits the plate, so the letters read on the oak.
